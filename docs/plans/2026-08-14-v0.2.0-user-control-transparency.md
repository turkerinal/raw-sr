# v0.2.0 User Control and Transparency Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers-optimized:subagent-driven-development (recommended) or superpowers-optimized:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add user control (Target ROI + Search Area, free-form SR ratio, adjustable adaptive threshold k) and transparency (motion analyzer feedback, 3-layer confidence map, requested-vs-achieved SR feedback, low-coverage warning, non-destructive view transform, baked export) to the existing v0.1.0 pipeline.

**Architecture:** The v0.2.0 pipeline extends v0.1.0 by inserting ROI management and residual-based validation between registration and fusion. New modules: `motion_analyzer.py` (inter-frame shift statistics + sufficiency feedback), `roi_manager.py` (Target ROI + Search Area state with defaults to full intersection), `sr_ratio_analyzer.py` (compute measurement-supported achievable SR given requested ratio), `validation.py` (reprojection residuals + adaptive threshold scaled by SR ratio), `confidence.py` (3-layer: coverage, SNR, registration confidence). The `registration.py` module gains a Search Area-aware method and subpixel phase correlation on the green channel. The `fusion.py` module gains an SNR map output. The `export.py` module gains baked export (view-transform applied) and a metadata JSON report (`metadata/report.py`). The UI gains: file panel with blur thumbnails + override, preview panel with ROI/Search Area rectangle drawing, result panel with before/after slider, confidence overlay toggle, brightness/contrast sliders, SR ratio input + achievable feedback, export dialog (master vs baked). The `worker.py` emits progress messages and a final `result_data` dict containing `{linear_rgb, confidence_map, report}`.

**Tech Stack:** Python 3.14, PySide6 (Qt6), rawpy + LibRaw, NumPy, OpenCV, pytest. New: `tifffile` for TIFF export (already present), `scipy` for phase correlation (already a dependency).

**Assumptions:**
- Assumes v0.1.0 is complete and tagged (57 tests passing, real DNG verified) — will NOT proceed if v0.1.0 is not baseline.
- Assumes the existing `RegistrationEngine.register_all` and `FusionEngine.fuse` interfaces are stable entry points — will NOT change their signatures for v0.1.0 callers without updating the worker and tests together.
- Assumes Bayer pattern detection works (confirmed in v0.1.0) — will NOT re-detect patterns per frame in batch.
- Assumes user provides 15+ frames of a static scene (acceptance criterion) — will NOT produce meaningful SR with fewer than 3 frames (pipeline proceeds but warns).
- Assumes the green channel of the Bayer demosaic is available for subpixel phase correlation — will NOT work if demosaic produced grayscale-only output.

# raw_sr/core/roi_manager.py
"""ROI Manager — Target ROI + Search Area management (v0.2.0)."""
from dataclasses import dataclass, field
from typing import Optional, Tuple, List

import numpy as np


@dataclass
class ROIManager:
    """Manages Target ROI and independent Search Area rectangles.

    - Target ROI: the region to be super-resolved.
    - Search Area: the region used for feature matching / homography estimation.

    If both unset → defaults to full frame intersection.
    If Target set but Search Area unset → proposes an enlarged Search Area.
    """

    frame_shape: Tuple[int, int]  # (height, width)
    _target_roi: Optional[Tuple[int, int, int, int]] = None  # (x, y, w, h)
    _search_area: Optional[Tuple[int, int, int, int]] = None  # (x, y, w, h)
    _frame_coverage: List[Tuple[bool, float]] = field(default_factory=list)

    def set_target_roi(self, roi: Tuple[int, int, int, int]) -> None:
        """Set the Target ROI as (x, y, w, h)."""
        self._target_roi = roi

    def set_search_area(self, area: Tuple[int, int, int, int]) -> None:
        """Set the Search Area as (x, y, w, h)."""
        self._search_area = area

    def set_frame_coverage(self, coverage: List[Tuple[bool, float]]) -> None:
        """Set per-frame coverage info: (is_usable, coverage_fraction)."""
        self._frame_coverage = coverage

    def get_effective_regions(self) -> Tuple[Tuple[int, int, int, int], Tuple[int, int, int, int]]:
        """Return effective (target_roi, search_area), with defaults applied.

        Returns:
            Tuple of (target_roi, search_area), each as (x, y, w, h).
        """
        h, w = self.frame_shape
        full = (0, 0, w, h)

        target_roi = self._target_roi if self._target_roi is not None else full

        if self._search_area is not None:
            search_area = self._search_area
        elif self._target_roi is not None:
            # Propose an enlarged search area around the target ROI
            search_area = self._compute_enlarged_search_area(target_roi)
        else:
            search_area = full

        return target_roi, search_area

    def _compute_enlarged_search_area(self, target: Tuple[int, int, int, int], margin_ratio: float = 0.5) -> Tuple[int, int, int, int]:
        """Compute an enlarged search area around the target ROI.

        Args:
            target: (x, y, w, h) of the target ROI.
            margin_ratio: Fraction of target size to add as margin on each side.

        Returns:
            (x, y, w, h) of the enlarged search area, clamped to frame bounds.
        """
        h, w = self.frame_shape
        tx, ty, tw, th = target
        margin_x = int(tw * margin_ratio)
        margin_y = int(th * margin_ratio)
        sx = max(0, tx - margin_x)
        sy = max(0, ty - margin_y)
        sw = min(w - sx, tw + 2 * margin_x)
        sh = min(h - sy, th + 2 * margin_y)
        return (sx, sy, sw, sh)

    def get_coverage_stats(self) -> Tuple[int, int]:
        """Return (usable_frame_count, total_frame_count)."""
        total = len(self._frame_coverage)
        usable = sum(1 for usable, _ in self._frame_coverage if usable)
        return usable, total
```

# raw_sr/core/motion_analyzer.py
"""Motion analyzer — inter-frame shift estimation + sufficiency feedback (v0.2.0)."""
import numpy as np
import cv2
from typing import List, Tuple, Dict, Any


class MotionAnalyzer:
    """Estimates inter-frame shifts and provides sufficiency feedback.

    Uses ORB + RANSAC homography to compute per-frame shift relative to
    the reference frame, then reports statistics and whether the motion
    is suitable for subpixel SR.
    """

    def __init__(self, min_useful_shift: float = 0.1, max_usable_shift: float = 5.0):
        """
        Args:
            min_useful_shift: Below this avg shift, motion is "too small" for SR.
            max_usable_shift: Above this avg shift, motion may cause misalignment.
        """
        self.min_useful_shift = min_useful_shift
        self.max_usable_shift = max_usable_shift

    def estimate_shifts(self, frames: List[np.ndarray], homographies: List[np.ndarray] = None) -> List[Tuple[float, float]]:
        """Estimate (dx, dy) shift of each frame relative to reference.

        Args:
            frames: List of RGB/uint8 images.
            homographies: Optional pre-computed homographies. If None, estimated internally.

        Returns:
            List of (dx, dy) shifts per frame (frame 0 is (0, 0)).
        """
        if homographies is None:
            from raw_sr.core.registration import RegistrationEngine
            engine = RegistrationEngine()
            homographies = engine.register_all(frames)

        shifts = []
        for H in homographies:
            # Extract translation from homography (assuming small rotation/skew)
            # H maps reference→target. The translation components are H[0,2], H[1,2].
            dx = float(H[0, 2])
            dy = float(H[1, 2])
            shifts.append((dx, dy))

        return shifts

    def analyze(self, frames: List[np.ndarray], homographies: List[np.ndarray] = None) -> Dict[str, Any]:
        """Analyze motion sufficiency across a frame set.

        Returns a dict with:
            - avg_shift: average Euclidean shift magnitude (pixels)
            - max_shift: maximum shift magnitude
            - shifts: per-frame (dx, dy) list
            - sufficient: whether motion is suitable for subpixel SR
            - message: human-readable feedback string
        """
        shifts = self.estimate_shifts(frames, homographies)
        # Skip frame 0 (identity) for statistics
        non_zero_shifts = shifts[1:] if len(shifts) > 1 else shifts
        magnitudes = [np.sqrt(dx**2 + dy**2) for dx, dy in non_zero_shifts]

        avg_shift = float(np.mean(magnitudes)) if magnitudes else 0.0
        max_shift = float(np.max(magnitudes)) if magnitudes else 0.0

        sufficient = self.min_useful_shift <= avg_shift <= self.max_usable_shift

        if avg_shift < self.min_useful_shift:
            message = (f"Average inter-frame shift: {avg_shift:.2f}px — "
                       f"too small for subpixel SR (need ≥{self.min_useful_shift}px)")
        elif avg_shift > self.max_usable_shift:
            message = (f"Average inter-frame shift: {avg_shift:.2f}px — "
                       f"too large, frames may be misaligned")
        else:
            message = (f"Average inter-frame shift: {avg_shift:.2f}px — "
                       f"suitable for subpixel SR")

        return {
            'avg_shift': avg_shift,
            'max_shift': max_shift,
            'shifts': shifts,
            'sufficient': sufficient,
            'message': message,
        }
```

# raw_sr/core/sr_ratio_analyzer.py
"""SR Ratio Analyzer — requested vs. measurement-supported achievable SR (v0.2.0)."""
import numpy as np
from typing import List, Tuple, Dict, Any


class SRRatioAnalyzer:
    """Computes measurement-supported achievable SR ratio.

    The achievable SR is informed by subpixel phase diversity in the
    measured inter-frame shifts. The achievable ratio is capped by
    the actual diversity of fractional pixel offsets observed.
    """

    def __init__(self, base_scale: int = 1):
        """
        Args:
            base_scale: Base sampling grid (1 means original pixel spacing).
        """
        self.base_scale = base_scale

    def _fractional_bin_coverage(self, shifts: List[Tuple[float, float]], sr_ratio: float) -> float:
        """Estimate what fraction of subpixel bins are covered by the shifts.

        For an Nx SR ratio, there are N^2 subpixel positions per pixel.
        We bin the fractional parts of the shifts and count coverage.
        """
        if not shifts:
            return 0.0

        n_bins = int(np.ceil(sr_ratio))
        bin_size = 1.0 / n_bins
        covered = set()

        for dx, dy in shifts:
            fx = dx % 1.0  # fractional part
            fy = dy % 1.0
            bx = min(int(fx / bin_size), n_bins - 1)
            by = min(int(fy / bin_size), n_bins - 1)
            covered.add((bx, by))

        total_bins = n_bins * n_bins
        return len(covered) / total_bins if total_bins > 0 else 0.0

    def analyze(self, shifts: List[Tuple[float, float]], requested_ratio: float) -> Dict[str, Any]:
        """Analyze achievable SR given shifts and requested ratio.

        Args:
            shifts: List of (dx, dy) shifts per frame (including frame 0 = (0,0)).
            requested_ratio: User-requested SR ratio (e.g. 2.0 for 2x).

        Returns:
            Dict with:
                - requested: the requested SR ratio
                - achievable: measurement-supported achievable SR ratio
                - coverage_fraction: fraction of subpixel bins covered
                - message: human-readable feedback
        """
        n = len(shifts)
        if n < 2:
            achievable = 1.0
            coverage = 0.0
        else:
            # Estimate achievable based on shift diversity and frame count
            # More frames + more diverse shifts → higher achievable SR
            # Cap by sqrt(n) (Nyquist-like limit on independent subpixel samples)
            max_by_count = min(np.sqrt(n), requested_ratio)
            coverage = self._fractional_bin_coverage(shifts, requested_ratio)
            # Achievable is the minimum of what diversity supports and what frames allow
            diversity_limited = coverage * requested_ratio
            achievable = min(max_by_count, diversity_limited, requested_ratio)
            achievable = max(1.0, achievable)  # at least 1x (denoise-only)

        if achievable >= requested_ratio * 0.8:
            message = f"Requested SR: {requested_ratio:.1f}x — measurement-supported achievable: ~{achievable:.1f}x"
        else:
            message = (f"Requested SR: {requested_ratio:.1f}x — measurement-supported "
                       f"achievable: ~{achievable:.1f}x (insufficient subpixel diversity)")

        return {
            'requested': float(requested_ratio),
            'achievable': float(achievable),
            'coverage_fraction': float(coverage),
            'message': message,
        }

    def compute_residual_threshold(self, residuals: np.ndarray, k: float, sr_ratio: float) -> float:
        """Compute adaptive residual threshold scaled by SR ratio.

        threshold = median(residuals) + k * MAD(residuals)

        The threshold is tightened (reduced) for higher SR ratios because
        more subpixel precision is demanded.

        Args:
            residuals: Array of reprojection residuals.
            k: User-adjustable MAD multiplier (strict↔tolerant).
            sr_ratio: Requested SR ratio (scales the threshold).

        Returns:
            Adaptive threshold value (pixels).
        """
        median_res = float(np.median(residuals))
        mad_res = float(np.median(np.abs(residuals - median_res)))

        # Lower MAD scale factor for higher SR ratios (stricter)
        # At 1x, full tolerance; at higher ratios, scaled down
        # e.g. 1x → 1.0, 2x → 0.707, 4x → 0.5
        scale = 1.0 / np.sqrt(max(sr_ratio, 1.0))

        threshold = (median_res + k * mad_res) * scale
        return threshold
```

# raw_sr/core/validation.py
"""Validation — back-projection residual + adaptive threshold (v0.2.0)."""
import numpy as np
import cv2
from typing import List, Tuple
from raw_sr.core.sr_ratio_analyzer import SRRatioAnalyzer


class Validator:
    """Validates frame alignment via back-projection residuals.

    Computes reprojection residuals by warping a frame with its homography,
    then warping back with the inverse, and measuring pixel difference.
    Frames exceeding the adaptive threshold are excluded.
    """

    def __init__(self, sr_analyzer: SRRatioAnalyzer, k: float = 3.0, sr_ratio: float = 1.0):
        """
        Args:
            sr_analyzer: SRRatioAnalyzer instance for threshold computation.
            k: MAD multiplier (strict↔tolerant slider).
            sr_ratio: Requested SR ratio (scales threshold).
        """
        self.sr_analyzer = sr_analyzer
        self.k = k
        self.sr_ratio = sr_ratio

    def compute_residuals(self, frames: List[np.ndarray], homographies: List[np.ndarray]) -> np.ndarray:
        """Compute per-pixel back-projection residuals for each frame.

        For each frame (except the reference), warp to reference coords using H,
        then warp back using H^{-1}, and measure the difference.

        Returns:
            Array of mean per-frame residuals (one per frame).
        """
        if len(frames) < 2:
            return np.zeros(len(frames))

        residuals = []
        ref = frames[0]
        ref_gray = cv2.cvtColor(ref, cv2.COLOR_RGB2GRAY) if ref.ndim == 3 else ref.astype(np.uint8)

        for i, (frame, H) in enumerate(zip(frames, homographies)):
            if i == 0:
                residuals.append(0.0)
                continue

            # Warp frame to reference coords
            h, w = ref.shape[:2]
            aligned = cv2.warpPerspective(frame, H, (w, h), flags=cv2.INTER_LINEAR)

            # Warp back using inverse homography
            H_inv = np.linalg.inv(H)
            back = cv2.warpPerspective(aligned, H_inv, (w, h), flags=cv2.INTER_LINEAR)

            # Compute residual as mean absolute difference
            frame_gray = cv2.cvtColor(frame, cv2.COLOR_RGB2GRAY) if frame.ndim == 3 else frame.astype(np.uint8)
            back_gray = cv2.cvtColor(back, cv2.COLOR_RGB2GRAY) if back.ndim == 3 else back.astype(np.uint8)

            # Only measure residual in the overlapping region
            aligned_gray = cv2.cvtColor(aligned, cv2.COLOR_RGB2GRAY) if aligned.ndim == 3 else aligned.astype(np.uint8)

            residual = float(np.mean(np.abs(frame_gray.astype(np.float32) - back_gray.astype(np.float32))))
            residuals.append(residual)

        return np.array(residuals)

    def validate(self, frames: List[np.ndarray], homographies: List[np.ndarray],
                 residuals: np.ndarray) -> List[bool]:
        """Validate frames against adaptive threshold.

        Returns:
            List of bool — True = frame is usable, False = excluded.
        """
        if len(residuals) == 0:
            return []

        # Compute threshold using sr_ratio_analyzer
        median_res = float(np.median(residuals))
        mad_res = float(np.median(np.abs(residuals - median_res)))

        threshold = self.sr_analyzer.compute_residual_threshold(residuals, self.k, self.sr_ratio)

        # Frame 0 (reference) always passes
        mask = [True]  # reference passes
        for i in range(1, len(residuals)):
            mask.append(residuals[i] <= threshold)

        return mask
```

"""Confidence Map — 3-layer confidence: coverage, SNR, registration (v0.2.0)."""
import numpy as np
from typing import Dict, Tuple, Optional


class ConfidenceMap:
    """Generates a 3-layer confidence map for the fused output.

    Layers:
        - coverage: how many frames contributed per pixel (integer count)
        - snr: estimated noise reduction in dB per pixel
        - registration: residual-based registration confidence [0, 1]
        - combined: weighted product of normalized layers
    """

    def __init__(self, frame_shape: Tuple[int, int, int], n_frames: int,
                 coverage_weight: float = 0.4, snr_weight: float = 0.3,
                 registration_weight: float = 0.3):
        """
        Args:
            frame_shape: (H, W, C) of the output.
            n_frames: Total number of input frames.
            coverage_weight, snr_weight, registration_weight: weights for combined layer.
        """
        self.h, self.w = frame_shape[:2]
        self.n_frames = n_frames
        self.weights = {
            'coverage': coverage_weight,
            'snr': snr_weight,
            'registration': registration_weight,
        }

    def compute(self, coverage_map: np.ndarray, snr_map: np.ndarray,
                registration_confidence: np.ndarray) -> Dict[str, np.ndarray]:
        """Compute all confidence layers.

        Args:
            coverage_map: HxW integer array of frame counts per pixel.
            snr_map: HxW float array of noise reduction in dB.
            registration_confidence: HxW array in [0, 1].

        Returns:
            Dict with 'coverage', 'snr', 'registration', 'combined' layers.
        """
        # Normalize coverage to [0, 1] relative to total frames
        coverage_norm = np.clip(coverage_map / max(self.n_frames, 1), 0.0, 1.0)

        # Normalize SNR to [0, 1] — assume 0–20 dB is the meaningful range
        snr_norm = np.clip(snr_map / 20.0, 0.0, 1.0)

        # Registration confidence already in [0, 1]
        reg = np.clip(registration_confidence, 0.0, 1.0)

        # Combined = weighted product
        combined = (
            coverage_norm ** self.weights['coverage'] *
            snr_norm ** self.weights['snr'] *
            reg ** self.weights['registration']
        )

        return {
            'coverage': coverage_map.astype(np.float32),
            'snr': snr_map.astype(np.float32),
            'registration': reg.astype(np.float32),
            'combined': combined.astype(np.float32),
        }

"""View Transform — non-destructive linear → display transform (v0.2.0).

Applies gamma correction, brightness, and contrast adjustments to the
linear master image for on-screen display and baked export.
The linear master itself is never altered.
"""
import numpy as np
from typing import Optional


class ViewTransform:
    """Non-destructive view transform for display and baked export.

    Args:
        gamma: Display gamma (default 2.2). Applied as inverse — pow(val, 1/gamma).
        brightness: Offset added after gamma [-1, 1].
        contrast: Multiplier around 0.5 midpoint [0, 2].
    """

    def __init__(self, gamma: float = 2.2, brightness: float = 0.0, contrast: float = 1.0):
        self.gamma = max(gamma, 0.1)
        self.brightness = np.clip(brightness, -1.0, 1.0)
        self.contrast = max(contrast, 0.0)

    def apply(self, linear_rgb: np.ndarray) -> np.ndarray:
        """Apply view transform to a linear RGB image.

        Args:
            linear_rgb: 3D float32 RGB array in [0, 1] range (linear).

        Returns:
            3D float32 RGB array in [0, 1] range (display-encoded).
        """
        # Work on a copy to avoid mutating the input
        display = np.clip(linear_rgb, 0.0, 1.0).astype(np.float32).copy()

        # Apply inverse gamma for display
        display = np.power(display, 1.0 / self.gamma)

        # Apply contrast around midpoint (0.5)
        display = (display - 0.5) * self.contrast + 0.5

        # Apply brightness offset
        display = display + self.brightness

        # Clamp to valid range
        return np.clip(display, 0.0, 1.0).astype(np.float32)

    def to_uint8(self, linear_rgb: np.ndarray) -> np.ndarray:
        """Apply view transform and return uint8 [0, 255]."""
        display = self.apply(linear_rgb)
        return np.clip(display * 255.0, 0, 255).astype(np.uint8)

from PySide6.QtWidgets import QLabel
from PySide6.QtGui import QPainter, QPen, QColor
from PySide6.QtCore import Qt, QRect, QPoint, Signal


class ROISelector(QLabel):
    """QLabel subclass that allows drawing rectangles for ROI/Search Area."""

    roi_changed = Signal(tuple)  # emits (x, y, w, h)

    def __init__(self, mode='target'):
        """
        Args:
            mode: 'target' or 'search' — determines rectangle color.
        """
        super().__init__()
        self._mode = mode
        self._rect = None  # QRect or None
        self._drawing = False
        self._start_pos = None

        self.setMouseTracking(True)
        self.setStyleSheet("border: 1px solid gray;")

        if mode == 'target':
            self._color = QColor(0, 255, 0, 180)  # green
        else:
            self._color = QColor(255, 255, 0, 180)  # yellow

    def set_pixmap(self, pixmap):
        """Set the base image pixmap."""
        self.setPixmap(pixmap)

    def clear_roi(self):
        """Clear the current ROI rectangle."""
        self._rect = None
        self.update()
        self.roi_changed.emit((0, 0, self.pixmap().width(), self.pixmap().height()))

    def paintEvent(self, event):
        """Draw the rectangle overlay."""
        super().paintEvent(event)
        if self._rect is not None:
            painter = QPainter(self)
            pen = QPen(self._color, 2, Qt.DashLine)
            painter.setPen(pen)
            painter.drawRect(self._rect)

    def mousePressEvent(self, event):
        if event.button() == Qt.LeftButton:
            self._drawing = True
            self._start_pos = event.pos()

    def mouseMoveEvent(self, event):
        if self._drawing and self._start_pos is not None:
            self._rect = QRect(self._start_pos, event.pos()).normalized()
            self.update()

    def mouseReleaseEvent(self, event):
        if self._drawing and self._start_pos is not None:
            self._drawing = False
            if self._rect is not None:
                roi = (self._rect.x(), self._rect.y(), self._rect.width(), self._rect.height())
                self.roi_changed.emit(roi)
